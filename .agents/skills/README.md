# Project design skills

These skills are available to contributors and compatible coding agents:

- `accaforge-ui-ux`: product-specific UX, design direction, component guidance, responsive behavior, accessibility, and responsible-play constraints for AccaForge.
- `unslop`: product-specific visual direction, spacing, color, typography, components and visual review.
- `no-ai-slop`: UI anti-pattern checklist and responsive/accessibility self-check.
- `impeccable`: frontend design, critique, polish and accessibility guidance.

For AccaForge product work, read `accaforge-ui-ux/SKILL.md` and `accaforge-ui-ux/DESIGN.md` first, then use the other skills as supporting review tools.
