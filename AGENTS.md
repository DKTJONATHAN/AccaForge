# Repository guidance

For every AccaForge interface change, read DESIGN.md first and apply the visual direction during implementation, not as a final polish pass.

Use the anti-slop purpose test and convergence test from https://github.com/muris11/anti-ai-slop:
- Avoid generic gradients, glows, repeated cards and decorative icon containers.
- Let football editorial content determine hierarchy and layout.
- Keep every visible link functional.
- Use real, locally hosted, credited football imagery.
- Test mobile layout, readable contrast, reduced motion and fallback states.
- Never fabricate football data, endorsements, testimonials or guaranteed outcomes.
